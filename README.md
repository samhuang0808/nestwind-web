### 一、 專案背景與痛點分析

- **異地孤獨與兩點一線**：初到新竹求學（清大、交大）或在竹科工作的異鄉人，生活圈高度受限於租屋處與實驗室/公司，缺乏探索環境與建立在地連結的動機。
- **效率搜尋 vs. 情感傾聽的衝突**：使用者白天需要高效率的店家與交通指引，深夜則需要不被評判的情感陪伴。若做成純資訊工具會缺乏溫度，做成純聊天機器人又缺乏實用價值。
- **弱連結結夥需求**：想找伴外出用餐，但傳統交友軟體容易帶來社交壓力與安全隱憂，需要一種「各自安靜用餐、不尬聊、低負擔」的默契同行機制。
- **前期調研與迭代關鍵**：延續前期量化調研「地圖標記功能」與整體滿意度呈現中高度正相關（r = 0.75）的核心優勢，並將語音發聲主動權回歸使用者（手動觸發），杜絕自動外放干擾。

---

### 二、 系統架構與技術選型

- **檔案結構**：單一檔案（`index.html`），無編譯器依賴，靜態相容於 GitHub Pages。
- **視覺樣式**：Tailwind CSS (CDN)，全站採用大地暖色調設計與響應式佈局（RWD）。
- **向量圖示**：Lucide Icons 與 FontAwesome 向量圖示（CDN）。
- **地圖圖資**：Leaflet.js + ESRI World Street Map 高清街景圖資（完全免 API Key、零浮水印、無 403 阻擋，內建新竹坐標範圍保護）。
- **外部導航**：Google Maps Universal URL API，以標準格式開新分頁直接啟動外部地圖導航。
- **語音互動**：Web Speech API（SpeechSynthesis），鎖定繁體中文（zh-TW）在地女聲，調校 0.90 沉穩語速與 1.02 暖心音調。
- **資料持久化**：Browser LocalStorage API，名片、日記、成就卡、同行邀約與筆記於重新整理後完整保留。

### 三、 六大核心功能模組

1. **異鄉人身分登錄（虛擬名片）**
   - 首次進入免註冊即可建立個人名片（稱呼、家鄉）。
   - 頂端常駐名片徽章，對話與回信皆動態帶入個人暱稱。

2. **雙重對話模式 (Dual Mode Engine)**
   - 模式開關即時分流「🗺️ 地圖探索找店」與「💬 心靈樹洞陪伴」。
   - 導入「1/3 精選決策法」，針對火鍋、牛排、小吃、老屋咖啡、居酒屋、單車與公車推薦 Top 3 高星好店。
   - 每張推薦卡片附真實 Google 評分（如 ⭐4.7）、評論數、地址、App 定位按鈕與 Google 導航。
   - 手動語音朗讀（「🎧 聽聽暖心絮語」）取代自動外放，並支援麥克風語音轉文字輸入。

3. **遊戲化靈感占卜任務 (Gamified Quest)**
   - 隨機抽取「生活犒賞卡」或「心靈雞湯卡」。
   - 點擊「接受任務」後，地圖自動平移聚焦目標坐標。
   - 到達地點點擊打卡後，卡片觸發金色高光邊框並永久收錄至成就庫。

4. **新竹生活足跡地圖全覽 (Hsinchu Map)**
   - 收錄 34 處新竹在地真實高星坐標，包含打卡熱點、慢活漫遊、老屋咖啡、特色小吃等 11 大類別。
   - 點擊圖釘彈出詳細氣泡框，整合「Google 地圖導航」與「🤝 一鍵發起微光同行」。

5. **封蠟心情日記與時光膠囊 (Mood Diary)**
   - 100% 個人私密樹洞保證，信件僅寄給虛擬夥伴「棲風」。
   - 結合情緒表情與新竹足跡地點，寄出後展現火漆封蠟開信動效與專屬回信。
   - 時光膠囊清單記錄歷史篇數統計，支援點擊歷史條目重溫信件與語音重播。

6. **微光同行公佈欄 (Silent Hangout Board)**
   - 提供「各自用餐、各付各的、不尬聊」的弱連結同行倡議。
   - 支援 8 大默契情境標籤與「自創自訂默契標籤」輸入。
   - 點擊「🤝 默默同行 (+1)」即時累加人數並掛入虛擬名片標籤。

### 四、 人機協同討論與規格演進歷程

- **階段一：提出原始需求與痛點**
  - 提出外地人在新竹生活單一、深夜孤獨無助的困境，分析原先原型在「資訊搜尋」與「純陪伴」間的衝突，確立以 Vibe Coding 打造單一靜態網頁並部署於 GitHub Pages 的目標。
- **階段二：AI 架構診斷與收斂**
  - AI 專家確立四項核心架構：雙重模式分流、取消自動外放改為手動語音、採用免金鑰開源地圖防止額度與安全風險、使用 LocalStorage 本地儲存資料。
- **階段三：遊戲化與儀式感設計**
  - 規劃「靈感占卜任務卡」結合地圖平移下沉圖釘與金色成就轉換；設計「封蠟心情日記」帶來情感結算儀式感。
- **階段四：評估社群連線可行性**
  - 針對會員與結夥需求，考量 GitHub Pages 無後端限制，重構為「異鄉人免註冊虛擬名片」與「微光同行公佈欄」，兼顧互動深度與系統穩定度。
- **階段五：拍板最終規格書與單檔架構**
  - 正式定名為「棲風 (NestWind)」，整合雙重對話、手動語音、占卜、地圖、封蠟日記、同行公佈欄與收藏庫六大模組。
- **階段六：Vibe Coding 實作測試與深度迭代**
  - 修復 OpenStreetMap 403 阻擋與圖磚水印問題，全面改採 ESRI 高清圖資並鎖定新竹邊界防漂移。
  - 導入「1/3 精選法」擴充至 34 處在地地標（含火鍋、牛排、小吃、居酒屋、十八尖山、魚鱗天梯等），加入真實 Google 星級。
  - 確立封蠟日記個人私密定位，增加時光膠囊歷史展開回溯。
  - 地圖氣泡框全面整合一鍵發起同行，並新增自創默契標籤功能。
